PACOTE PARA MELHORAR AS ARMAS — Riposte: Frontline (snapshot 5.6.0)
================================================================================

Responda em português se o dono pedir. Entregue patches/arquivos .js prontos
para copiar em src/ (ou em armas-para-editar/). O jogo concatena src/*.js em
ordem alfabética via `python build.py` → dist/riposte-frontline.html.

--------------------------------------------------------------------------------
1) ONDE ESTÃO OS MATERIAIS E HELPERS (pedido #1)
--------------------------------------------------------------------------------
Pasta: 1-materiais-e-helpers/

  06-weapons.js     ← gunMaterials(), gunWear(), gunSurfPatch (shader de desgaste),
                      part(), bx(), cz(), GM, viewmodel (VM), flash, shells
  06c-models.js     ← rb(), cy(), rail(), curvedMag(), rgeo()  (helpers de peça)
  06jb-formes.js    ← prof(), guard(), cone(), iron*, gripProf() (perfis extrudados)
  06j-modeles.js    ← buildGunModel(), gunKey(), grips
  06i-armes.js      ← WEAPONS (stats), FEEL, CLASSES
  06cy-ressorts.js  ← molas / sensação do viewmodel
  06p / 06q         ← acessórios e camos
  06l…06oa         ← modelos 3D das outras armas (AK, SCAR, etc.)

--------------------------------------------------------------------------------
2) RENDERER / CENA / FP (pedido #2)
--------------------------------------------------------------------------------
Pasta: 2-renderer-cena/

  01-core.js   ← WebGLRenderer, scene, vmScene, vmCamera, luzes do viewmodel
                 (vmHemi/vmSun/vmFlash/vmLamp), EffectComposer (bloom, rays, SSAO,
                 final grade), setEnvMap / HDRI / PMREM, shadow cascades
  01a-gpu.js   ← qualidade, lean mode celular, perda de contexto
  08-player.js ← jogador + vista 1ª pessoa (ADS, FOV, updateViewmodel chamado daqui)

Arquitetura importante:
  - Three.js r147, bundle único (NÃO usa import de three/addons no browser do jogo).
  - HTML único: dist/riposte-frontline.html + dist/tex/ + dist/sfx/
  - renderer.toneMapping = NoToneMapping (tomemapping no post FinalShader)
  - renderer.outputEncoding = LinearEncoding
  - scene.environment E vmScene.environment = mesmo envMap (HDRI da carta ou céu)
  - Armas em 1ª pessoa = cena SEPARADA (vmScene) composta depois do mundo
  - NÃO use: import('three/addons/...') — quebra o build. Já tentamos e removemos.

Versão Three: 0.147.0 (também em tools/dev/package.json).

--------------------------------------------------------------------------------

  Se estiver vazia: o dono tira prints no jogo local

      --armes m4,ak47,scarh,mp5,l96,m1014,m9,deagle,m82 --vues hanche,ads
